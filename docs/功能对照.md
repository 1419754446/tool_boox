# 原版三套 vs 合并版：功能对照与差异清单

更新时间：2026-11-26（对应 `Toolbox.exe` 0.4.0，本轮补齐扩展名勾选、右键隐藏/退出、悬浮窗自动高度、任务栏开关、独立预览窗）

合并版不是把三个程序简单拼在一起，而是以 `tool_soft` 的外壳为底座，把
`_desktop_links`（常用文件夹）和 `video-collector`（视频整理）的命令与后台
引擎接进同一套 **C++20 + Win32 + WebView2 + JSON 命令总线**。下表以源码为准，
不以 README 的功能宣称作为实现证据。

## 0. 这轮是怎么核对的

| 项目 | 实际读的源码 | 核对结果 |
| --- | --- | --- |
| 常用文件夹 | `_desktop_links/DesktopFolders.cs`（约 125 KB），重点看 `MoveSelected` / `DeleteSelected` / `OpenListFile` / `ListKeyDown` / 右键菜单构建 / 磨砂绘制 | 清单增删改、位置记忆、快捷键、批量移动、右键菜单逐项对照；未搬的是磨砂抓屏和自动高度 |
| 视频整理 | `VideoCollectorWeb/src/main.cpp`、`backend.cpp`、`ui/app.js`；原版 18 个 `api(cmd)` 命令逐个对 | 发现缺 `report_html`、`save_settings`、`preview_popout`、`undo_available` 等行为；本轮补了 HTML 报告、设置持久化、批量删除/快捷键 |
| `tool_soft` 14 工具 | 原 `src/app.cpp` 的 37 个 `type == "..."` 消息分支，和合并版逐条 diff | 37 个原生消息分支全部保留；合并版只多了 `miniOpen` / `miniOpenMain` |
| 三个前端 | `tool_soft/web/app.js`（197 个具名函数）、`VideoCollectorWeb/ui/app.js`、合并版 `web/app.js` | 原版具名函数无缺失；但运行时逐页审计发现「快速文件搜索」是空白页，已补 `renderQuickSearch` / `handleSearchDone` |

这次不是“看 README 觉得像”，而是把命令、页面分支、事件处理和运行时状态都过了一遍。
下面标 ✅ 的，至少有一条对应的命令或页面路径；标 ❌ 的，是代码里确实没有。

## 4. 这一轮真正补齐的东西

1. **通用 WebView2 悬浮窗**：`src/mini_window.*`，每个悬浮窗是独立 Win32 窗口 + 独立 WebView2 控制器，共享同一份内嵌页面和命令总线；支持置顶、收起、关闭、拖动、四角吸附、位置/尺寸/收起状态记忆。
2. **悬浮工具箱**：托盘「悬浮工具 → 悬浮工具箱」打开一个 16 格启动面板，点任意工具直接再开一个小窗，不用回主页面。
3. **常用文件夹浮窗全功能**：搜索高亮、新增/编辑/删除、上移下移、**Shift 连选 + Ctrl+A**、**多选整块上/下移**、**右键 12 项菜单**、`Insert` 新增、`F2` 编辑、`Delete` 批量删、数字键打开、底栏匹配数。
4. **视频预览播放**：`video.preview` + `https://media.local` 的 Range 文件处理器（`src/media_handler.*`），不整文件读内存、支持拖动进度条；双击行或播放按钮打开，失败回退系统播放器。
5. **视频缺口回补**：设置用 `localStorage` 持久化；HTML 自包含报告（`exportVideoHtml`）；批量删除选中；`Ctrl+F` / `Ctrl+A` / `Enter` / `Delete` / `Esc` 快捷键。
6. **任意工具悬浮**：每个工具页 `pageHead` 自动带「悬浮」按钮；`miniOpen` 消息走原生 `ShowMiniWindow`。
7. **快速文件搜索空白页修复**：原 `tool_soft` 源码里就是空引用，合并版补上页面和结果渲染。
8. **悬浮窗快捷键冲突修复**：原 `tool_soft` 的全局 `Escape` 会执行 `navigateHome()`，导致在悬浮窗按 Esc 直接跳回首页；现在 mini 模式直接跳过全局导航快捷键。
9. **0.3 视觉与悬浮窗**：重做设计令牌/卡片/表单/表格，迷你顶栏补「打开主窗口」，默认尺寸收紧，
   悬浮工具箱加搜索过滤，设置页加悬浮窗入口，顶栏加 `F1` 帮助入口。
10. **0.3 视频细节**：表头半选、删除时连带目标副本、扫描设置折叠。
11. **0.4 遗留缺口回填**：扩展名勾选面板、文件夹右键「隐藏 / 退出」、悬浮窗高度随条目数
    （含外框/客户区尺寸修正）、任务栏显示开关、独立视频预览窗、扫描后内容分组。

## 5. 仍未做（明确的缺口）

- 常用文件夹：原版 `PaintGlass` / `PaintGrain` 的抓屏磨砂玻璃（不建议照搬，见第 6 节）。
- 视频整理：四步向导已由单页设置条替代，建议不再恢复。
- `tool_soft` 的 37 个原生消息分支都在，但个别工具页在 760px 小窗下表格列偏挤，需要手动拉大窗口。

这些缺口不影响主流程，且都可以在现有架构上增量补，不需要改技术路线。
